# Kindle calendar

Step-by-step setup (GitHub + Kindle): **[SETUP.md](SETUP.md)**

Short version:

1. Push this repo (without secret config files)
2. Add GitHub secret `ICS_URL` + enable Pages (Actions)
3. Copy `extensions/calendar` to the Kindle and set `bin/config` → `CALENDAR_URL`
4. KUAL → **Calendario → Actualizar y mostrar**
